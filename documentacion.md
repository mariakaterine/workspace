# Documentación de Código

## ¿Cómo se documenta el código Frontend y cuál es la diferencia con Backend?

El código Frontend es la parte de una aplicación o página web que el usuario puede ver e interactuar. Se puede documentar explicando la estructura de las páginas, los componentes, las funciones y el funcionamiento de cada elemento.

El código Backend es la parte que funciona detrás de la aplicación. Se encarga de procesos como bases de datos, servidores, autenticación y APIs.

La principal diferencia es que el Frontend se enfoca en la interfaz y la interacción con el usuario, mientras que el Backend se encarga de la lógica y los datos que funcionan en el servidor.

## ¿Cómo se documenta código CSS?

El código CSS se puede documentar utilizando comentarios para explicar qué parte del diseño se está modificando.

Ejemplo:

/* Estilos del encabezado */
.header {
  background-color: blue;
  padding: 20px;
}

Los comentarios ayudan a identificar y entender las diferentes secciones de los estilos.

## ¿Cómo se documenta código JavaScript?

En JavaScript se pueden utilizar comentarios para explicar funciones, variables o procesos importantes.

Ejemplo:

// Función para mostrar un mensaje
function mostrarMensaje() {
  alert("Hola");
}

También se pueden utilizar comentarios de varias líneas cuando se necesita explicar un proceso más largo.

## ¿Cómo se documenta código React?

En React se recomienda documentar los componentes explicando cuál es su función, qué información reciben y qué comportamiento tienen.

Ejemplo:

// Componente que muestra el saludo
function Saludo() {
  return <h1>Hola</h1>;
}
